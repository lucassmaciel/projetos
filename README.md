# Projetos de estudo

Coleção de exercícios e projetos pequenos de várias disciplinas e estudos.

| Pasta | Conteúdo |
|---|---|
| `cpp/nee_interpreter` | Fila, lista e pilha em C++ |
| `java/exercicio` | Projeto Maven inicial |
| `java/todolist` | Gerenciador de tarefas em Spring Boot |
| `node/` | Exercícios de Node.js |
| `react/01` | Componentes React com carrinho |
| `react/02` | Site de catálogo de livros com rotas em React |
| `react/meu-crud-mongo` | CRUD com React e MongoDB |
| `vc/` | Notebooks introdutórios de visão computacional |

Cada pasta tem o próprio `package.json`, `pom.xml` ou notebook. Para rodar, entre na pasta e use o comando da ferramenta (`npm install && npm start`, `./mvnw spring-boot:run` ou `jupyter notebook`).
